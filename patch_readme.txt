CHANGES TO THE GAME
Subtitles were added to the animated cutscenes, which previously did not have any. The ability to use the left analogue stick was added to the present giving menu, making it consistent with other menus.

SAVE GAME TEXT
Save games are fully compatible between the patched and unpatched versions. Any saves made in the unpatched version of the game will still show the save information in Japanese, even if you overwrite the file. In order to view the translated text, you must save the game into an empty slot.
